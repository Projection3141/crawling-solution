수집 성공 및 트래픽 사용량
천유 기존 일반수집과 상세수집은 각각 1페이지 기준으로 성공했습니다. 사용자 확인 기준 사용량은 일반수집 1페이지당 0.02GB, 상세수집 1페이지당 1.6GB입니다.

네이버 커머스 페이지의 상품 정보를 수집하는 기능도 추가했습니다. 운영 측에서는 천유와 마찬가지로 계정·IP별 이용량 제한이 있는 것으로 파악하고 있어, 가정용 프록시를 적용한 수집 테스트를 진행하고 있습니다.

02 / 접속 방식의 변화

고정 IP 중심에서 회전·고정 유지의 2가지 운용으로

도입 배경 · 운영 과정에서 천유의 접속 차단(밴)을 경험했으며, 운영 측은 IP별·계정별 트래픽 사용량에 따른 제재로 파악했습니다. 이에 공개 정보는 비로그인으로 수집해 로그인 계정과 직접 연결되는 요청을 줄이고, 가정용 프록시의 IP 회전(셰이킹)을 활용하기로 했습니다. 재고·옵션별 바코드 확인에 필요한 로그인 작업은 별도로 분리했습니다.

기존 고정형 ISP 프록시는 등록한 IP를 중심으로 연결합니다. 일반적인 ISP 상품은 통신사에 등록된 IP를 서버 인프라에서 제공합니다. 새로 적용한 Residential은 실제 가정용 회선의 IP 풀을 이용하며, 공개 정보 수집에는 회전 연결을, 로그인 작업에는 일정 시간 같은 IP를 유지하는 스티키 연결을 적용합니다.

Residential을 적용하면서 IP를 개별 등록하는 방식 외에 공급자의 IP 풀을 사용할 수 있게 됐습니다. 반면 가정 회선 상태에 따라 응답 시간과 IP 유지 시간이 달라질 수 있고, GB 사용량이 비용에 직접 연결됩니다. 기존 ISP 요금과 동일 조건의 측정 자료가 없어 ISP 대비 비용·속도·차단 감소율은 산정하지 않았습니다.

접속 구조와 일반적 특성 근거 · Decodo — ISP vs. Residential Proxies

스티키 세션은 일정 시간 같은 출구 IP를 유지하는 연결입니다.

로그인 → 재고 확인 → 장바구니 작업을 같은 IP로 이어가도록 두 공급자 모두 60분으로 설정했습니다. 앱은 30초 간격으로 IP를 확인하며, 50분 경과 후 페이지 저장과 장바구니 정리가 끝난 시점에 새 세션으로 갱신합니다. 로그인 쿠키와 계정 상태는 앱에서 별도로 관리합니다.

IP 회전 이후에도 로그인 계정은 동일하게 식별됩니다. 계정별 이용량 제한과 사이트의 접근 제한은 계속 적용됩니다.

숫자로 확인된 범위
천유 기존 수집 성공 범위는 일반 1페이지·상세 1페이지입니다. DataImpulse 테스트는 성공으로 확인됐으나, 반복 횟수·장시간 안정성·속도 개선율·이미지 차단에 따른 트래픽 절감률은 아직 수치화하지 않았습니다. 공급자의 최대 세션 설정값은 실제 IP 유지 시간을 보장하지 않습니다.
