브랜드 수집

천유에 로그인하여 브랜드별 스마트스토어 등록용 엑셀을 저장합니다.

위의 테스트 프록시와 브라우저 표시 설정을 사용합니다. 계정·프록시에 관계없이 앱 전체 하루 10회(한국 시간 자정 초기화). 요청 후 실패하거나 앱이 종료돼도 사용 횟수는 유지됩니다.

상품 정보 수집(커머스)

천유 커머스센터 전용 계정으로 상품을 조회합니다. 결과는 별도 JSON 파일로 저장하며, 이미지는 원본 주소만 기록합니다.

천유 상품 HTML 직접 요청

브라우저 없이 상품 한 개의 HTML만 요청합니다. 위에서 선택한 프록시를 사용하며 로그인은 하지 않습니다. 로그인 화면·접근 거부 응답은 상품으로 처리하지 않습니다.

기존 아카이브에서 같은 상품을 읽어 누락·차이를 비교합니다. 재고·옵션·번역처럼 다른 단계에서 만드는 항목은 별도로 표시합니다. 수집 결과와 아카이브는 수정하지 않습니다.
