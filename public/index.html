모든 수집 작업과 파일 저장은 현재 PC에서 실행됩니다. 프록시와 OpenAI API 키는 이 PC에 등록한 항목만 사용합니다.

일반 수집 제공 데이터

상품 ID, 상품명, 상품 URL, 목록상 품절 여부, 장바구니 옵션명, 옵션별 재고, 가격, 구매 가능 수량, 상품별 재고 요약을 수집합니다.

상세 수집 추가 데이터

상세페이지의 카테고리, 상품번호, 대표 바코드, 외부 박스 수량, 소비자가, 상품상세정보, 상품 소개 이미지 URL을 수집합니다.

페이지 범위 및 고급 공통 설정
