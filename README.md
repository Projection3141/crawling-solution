# Mall Collector Public UI

## 실행

```bash
npm install
npx playwright install chromium
cp .env.example .env
npm run web

브라우저 또는 Electron WebView에서 다음 주소를 엽니다.

http://127.0.0.1:3210

설정 우선순위

public 화면 입력 > .env 공통 설정 > 코드 기본값

계정 키는 쇼핑몰 구분 없이 다음 두 개만 사용합니다.

ACCOUNT_ID=
ACCOUNT_PW=

결과 파일

실행별로 다음 경로가 생성됩니다.

out/<mall>/<run-id>/
├─ inventory.csv
├─ summary.csv
├─ products.csv
├─ result.json
└─ debug-*.html

inventory.csv: 천유는 옵션별 수량, 과자생각은 판매 가능/품절 상태

summary.csv: 상품 단위 요약

products.csv: 수집한 전체 상품 목록

# 크롤링 프로그램 설치·실행 차단 시 조치 안내

본 프로그램은 회사 내부 업무용으로 제작된 Windows 데스크톱 프로그램입니다.

디지털 코드 서명이 적용되지 않은 배포본은 Windows Defender, Microsoft Defender SmartScreen 또는 Smart App Control에서 알 수 없는 앱으로 인식되어 설치나 실행이 차단될 수 있습니다.

> 아래 조치는 **회사에서 전달받은 정식 설치 파일이며 출처가 확실한 경우에만** 진행해 주세요.

---

## 1. 설치 파일 실행 시 `Windows의 PC 보호`가 표시되는 경우

설치 파일을 실행했을 때 다음과 같은 경고가 표시될 수 있습니다.

```text
Windows의 PC 보호
Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.
```

다음 순서로 진행합니다.

1. 경고 화면에서 `추가 정보`를 클릭합니다.
2. 표시된 파일명과 게시자 정보를 확인합니다.
3. 회사에서 전달받은 정식 설치 파일이 맞다면 `실행`을 클릭합니다.

`실행` 버튼이 없거나 계속 차단될 경우 다음 항목을 확인합니다.

---

## 2. Windows 보안의 보호 기록 확인

1. Windows 시작 메뉴에서 `Windows 보안`을 검색해 실행합니다.
2. `바이러스 및 위협 방지`를 선택합니다.
3. `보호 기록`을 엽니다.
4. 프로그램 설치 파일 또는 실행 파일과 관련된 탐지 내역을 확인합니다.
5. 회사에서 전달받은 정식 파일이 맞는지 확인한 후 표시되는 조치 중 하나를 선택합니다.

```text
장치에서 허용
복원
허용
작업 → 허용
```

Windows 버전에 따라 메뉴 이름은 다를 수 있습니다.

> 파일이 이미 격리되거나 삭제된 경우에는 허용 처리만으로 복원되지 않을 수 있습니다. 이 경우 허용 처리 후 설치 파일을 다시 전달받아 재설치해야 합니다.

---

## 3. 설치 파일의 차단 해제

설치 파일을 마우스 오른쪽 버튼으로 클릭한 후 다음 순서로 진행합니다.

1. `속성`을 선택합니다.
2. `일반` 탭 하단에 `차단 해제`가 표시되는지 확인합니다.
3. 표시된다면 `차단 해제`를 체크합니다.
4. `적용`을 누른 뒤 `확인`을 선택합니다.
5. 설치 파일을 다시 실행합니다.

```text
파일 우클릭
→ 속성
→ 차단 해제
→ 적용
→ 확인
```

---

## 4. PowerShell로 설치 파일 차단 해제

파일 속성에서 차단 해제가 되지 않는 경우 PowerShell을 사용할 수 있습니다.

설치 파일이 다운로드 폴더에 있는 경우:

```powershell
Unblock-File "C:\Users\사용자명\Downloads\MallCollectorSetup.exe"
```

실제 사용자명, 파일명 및 경로에 맞게 수정해야 합니다.

설치 파일이 포함된 폴더 전체를 차단 해제하려면:

```powershell
Get-ChildItem "C:\Users\사용자명\Downloads\설치파일폴더" -Recurse -File |
  Unblock-File
```

> 출처가 확인된 회사 배포 파일에만 사용해 주세요.

---

## 5. 설치 후 프로그램이 다시 차단되는 경우

설치는 완료됐지만 프로그램 실행 시 다시 차단되는 경우가 있습니다.

먼저 다음 위치를 확인합니다.

```text
Windows 보안
→ 바이러스 및 위협 방지
→ 보호 기록
```

프로그램 실행 파일 관련 항목이 있다면 정식 배포 파일임을 확인한 후 허용 또는 복원합니다.

프로그램은 일반적으로 다음 경로 중 하나에 설치됩니다.

```text
C:\Users\사용자명\AppData\Local\프로그램명\
C:\Users\사용자명\AppData\Local\Programs\프로그램명\
```

설치 경로를 직접 확인하려면 시작 메뉴의 프로그램 아이콘을 마우스 오른쪽 버튼으로 클릭한 뒤 `파일 위치 열기`를 선택합니다.

---

## 6. `spawn UNKNOWN` 오류가 표시되는 경우

다음 오류는 프로그램 내부 실행 파일이 Windows 보안 또는 사내 백신에 의해 삭제·격리·차단됐을 때 발생할 수 있습니다.

```text
Error: spawn UNKNOWN
```

다음 순서로 조치합니다.

1. Windows 보안의 `보호 기록`을 확인합니다.
2. 프로그램 관련 파일이 차단 또는 격리됐는지 확인합니다.
3. 회사에서 전달받은 정식 파일이 맞다면 허용 또는 복원합니다.
4. 이미 파일이 삭제된 경우 기존 프로그램을 제거합니다.
5. 설치 파일을 다시 전달받습니다.
6. 설치 파일 속성에서 `차단 해제`를 적용합니다.
7. 프로그램을 다시 설치하고 실행합니다.

허용 처리 후에도 동일한 오류가 발생하면, 이미 삭제된 파일이 복원되지 않은 상태일 수 있으므로 반드시 재설치해야 합니다.

---

## 7. 회사 내부 PC에서 계속 차단되는 경우

사내 보안 프로그램이나 중앙 보안 정책이 적용된 컴퓨터에서는 사용자가 직접 허용할 수 없을 수 있습니다.

다음 정보를 사내 전산 또는 보안 담당자에게 전달해 주세요.

```text
프로그램명
설치 파일명
설치 파일 경로
Windows 보안 보호 기록의 탐지명
차단된 날짜와 시간
오류 문구 전체
오류 화면 캡처
```

전산 담당자 요청 예시:

> 회사 내부 업무용으로 전달받은 프로그램입니다.  
> Windows Defender 또는 사내 보안 프로그램에서 설치·실행 파일을 차단하고 있으니 파일 검토 후 허용 등록을 요청드립니다.

---

## 8. 조치하지 말아야 할 사항

다음 조치는 권장하지 않습니다.

```text
Windows Defender 전체 비활성화
실시간 보호 장기간 해제
Smart App Control 임의 비활성화
출처가 불분명한 파일 허용
컴퓨터 전체 드라이브를 백신 제외 경로로 등록
```

회사에서 전달한 정식 설치 파일만 개별적으로 확인하고 허용해야 합니다.

## 9. 해결되지 않을 때 전달할 정보

아래 내용을 정리해 프로그램 담당자에게 전달해 주세요.

```text
Windows 버전
프로그램 설치 파일명
설치 여부
오류 발생 단계
오류 문구 전체
Windows 보안 보호 기록 화면
설치 파일 속성 화면
오류 화면 캡처
```

문의 예시:

> 크롤링 프로그램 설치 또는 실행 중 Windows 보안 차단이 발생했습니다.  
> Windows 버전: Windows 11  
> 오류 단계: 설치 후 프로그램 실행  
> 오류 문구: spawn UNKNOWN  
> 보호 기록 탐지 여부: 있음  
> 조치 내용: 허용 처리 후 재설치했으나 동일 현상 발생  
> 관련 화면을 함께 첨부합니다.

## 10. 요약 안내

> 본 프로그램은 회사 내부 업무용 프로그램이며, 코드 서명이 적용되지 않은 경우 Windows에서 알 수 없는 앱으로 인식할 수 있습니다.  
> 회사에서 전달받은 정식 파일이 맞는지 확인한 후 `추가 정보 → 실행`, 파일 속성의 `차단 해제`, Windows 보안의 `보호 기록 → 허용 또는 복원` 순서로 조치해 주세요.  
> 파일이 이미 삭제된 경우에는 허용 처리 후 설치 파일을 다시 받아 재설치해야 합니다.  
> Windows Defender 전체 비활성화는 권장하지 않습니다.
